# Employee Leave Management System

A simple Python-based Employee Leave Management System for managing employee information and leave requests.

## Features

- Add employees
- Apply for leave
- View employees
- View leave requests
- Validate employee existence before applying for leave

## Technologies Used

- Python
- Git
- GitHub

## Project Structure

```text
01/
├── data/
├── app.py
├── README.md
└── requirements.txt
```

## How to Run

1. Activate the virtual environment.
2. Run the application using:

```bash
python app.py
```

3. Follow the options displayed in the terminal.
